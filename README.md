# 🏥 Sistema de Saúde

Sistema web desenvolvido em Python com Flask.

## 🚀 Funcionalidades
- Cadastro de usuários
- Login seguro
- Agendamento de consultas
- Histórico de atendimentos

## 🛠️ Tecnologias
- Python
- Flask
- SQLite

## ▶️ Como rodar o projeto

pip install flask  
python app.py
